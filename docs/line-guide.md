# 5노드 사용법

사진과 질문과 정답을 표 한 장으로 넣고, 한 줄로 이어진 다섯 공정이 학습과 검증까지 끝낸다.
데이터 한 건이 워크이고, 공정이 스테이션이다. 검사에서 걸린 건은 NG 로 배출된다.

```
① 이미지 → ② 질문 형태 → ③ 정답 형태 → ④ 모델 학습 → ⑤ 검증
```

## 시작하기

```
vlmt new-line 내폴더 --name "부품 분류"     # 빈 5노드 프로젝트
vlmt edit 내폴더/line.yaml                  # 창이 열린다. 카드 ① 을 눌러 폴더나 표를 고른다
```

터미널 없이 쓰려면 `line.bat` 을 더블클릭합니다. 폴더 경로를 물어서, 새 폴더면 빈 프로젝트를 만들고 있는 폴더면 엽니다.
`line.yaml` 이나 폴더를 `line.bat` 위로 끌어다 놓아도 됩니다. 실행은 창의 `실행` 버튼입니다.

창에서는 이미 있는 예제(`solutions/vlm_open/projects/01_open/line.yaml`)도 열린다.
툴바의 `새 5노드…` 로도 같은 폴더를 만든다. YAML 을 손으로 쓸 일은 없다.

## 데이터 넣기 — 오른쪽 패널 ① ② ③

카드를 누르면 오른쪽 설정 칸에 그 스테이션의 패널이 뜬다. 사진이 ① 에서 들어오고, ② 에서 질문이 붙고,
③ 에서 정답이 붙는다. 입력 방식은 둘이다 — **사진 폴더**와 **표**.

**사진 폴더.** ① 에서 `사진 폴더` 를 고르면 작은 창이 폴더 · 질문 문장 · 정답 항목을 한 번에 받는다
(셋이 다 있어야 실행할 수 있는 상태가 된다). 하위 폴더가 있으면 그 이름들을 첫 항목의 허용값으로 미리 적어 둔다.

- 하위 폴더까지 파일 이름순으로 읽는다. `jpg · jpeg · png · bmp` 만 읽고 나머지는 건너뛰되 몇 개인지 보인다.
- 건 이름은 확장자를 뺀 파일 이름이고, 하위 폴더는 `__` 로 붙는다(`검정색/a01.jpg` → `검정색__a01`).
  이름만 같고 확장자가 다른 사진(`a.jpg`, `a.png`)은 거부한다.
- 화면이 `line.yaml` 옆에 `data.csv` 를 만든다. 엔진은 이 표를 읽는다 — 한 행이 한 건이다.
- 열 때와 `다시 읽기` 때 폴더와 표를 맞춘다. 새 사진은 정답이 빈 행으로 덧붙고(실행하면 ③ 에서 NG),
  사라진 사진의 행은 지우지 않고 `제외` 에 `x` 를 적는다. 입력해 둔 정답은 남는다.
- 학습/검증은 무작위로 나눈다(기본 검증 20%). ① 에서 비율과 `학습 n건 · 검증 m건` 이 보인다.

**① 이미지.** 첫 사진의 원본과 **모델이 보는 크기**가 나란히 보인다. 학습에 쓰는 바로 그 리사이즈로 그리므로
`사진 크기` · `가로세로 비 유지` 를 바꾸면 학습 때와 같은 그림이 된다. 글자나 결함이 뭉개지는지 여기서 본다.

**② 질문 형태.** `질문 문장` 에 `{image} 공의 색상은?` 처럼 적는다. `{image}` 는 사진 자리이고 **맨 앞이나 맨 뒤에만**
둔다(가운데는 거부한다 — 모델은 사진을 문장 앞이나 뒤에만 받는다). 표 방식이면 `{열 이름}` 으로 표의 값을 넣을 수 있다.
아래에 실제로 들어갈 질문이 한 줄 보인다.

**③ 정답 형태.** 위쪽은 정답 항목 표(항목 이름 · 종류 · 허용값), 아래쪽은 건별 정답 표(`Index · 건 · Q · A`)다.
줄을 고르면 사진이 크게 보인다. 정답 칸에 바로 적고 `저장` 을 누르면 표에 쓴다(저장 전에 닫으면 묻는다).

- `하위 폴더 이름으로 채우기` — 빈 정답 칸만 하위 폴더 이름으로 채운다. 적힌 값은 덮지 않고, 허용값에 없는 이름은 채우지 않는다.
- `CSV로 열기` — 수백 건은 엑셀에서 넣는다. 저장 안 한 정답이 있으면 먼저 저장할지 묻는다. 엑셀에서 고친 뒤 `다시 읽기`.
- 표가 엑셀(`.xlsx`)이나 JSONL 이면 보기 전용이다. CSV 로 저장해 쓴다.

터미널에서도 같은 일을 한다:

```
vlmt line-folder line.yaml 사진폴더 --question "{image} 공의 색상은?" --item "색상:목록:검정색|파란색|흰색"
vlmt row-fill-folder line.yaml 색상       # 빈 정답 칸을 하위 폴더 이름으로
vlmt row-set line.yaml 검정색__a01 색상=검정색
```

## 표로 넣기 — `데이터`

표 방식은 ① 의 `표 고르기 · 열 지정…`(또는 툴바 `데이터`)에서 정한다. 정답 항목을 처음 정한 뒤에는 ③ 에서 고치고,
이 창에서는 항목마다 표의 열만 고른다.

표 한 장에서 **한 행이 한 건**이다. 형식은 CSV(UTF-8)와 엑셀(`.xlsx`)이다. 표가 아직 없으면 `표 양식 만들기` 가 첫 줄을 써 준다.

1. 표 파일과 건 이름이 들어 있는 열을 고른다.
2. 사진 열, 질문 열, 정답으로 쓸 열을 고른다. 같은 이름의 열이 있을 때만 미리 골라 두고, 없으면 빈 칸이다.
3. **정답 항목**을 표로 적는다 — 항목 이름, 종류(목록·숫자·문장), 허용값. 목록은 `|` 로 구분하고,
   숫자는 `0~100` 처럼 범위를 적을 수 있다(비우면 숫자이기만 하면 된다). 범위 밖 정답은 ③ 에서 NG 로 나가고,
   모델이 범위 밖 숫자를 답하면 `검증 결과` 에 `범위 밖` 으로 표시된다.
4. 학습/검증 나누기를 고른다 — 구분 열을 쓰거나, 무작위로 비율을 나누거나, 같은 묶음끼리 한쪽에 몰아 나눈다.
   고르면 각각 몇 건이 되는지 바로 보인다.
5. `적용`. 어긋나면 이유가 창 안에 뜨고 아무것도 바뀌지 않는다.

**엑셀을 쓸 때.** `.xlsx` 를 고르면 `시트` 칸이 나타난다(처음엔 첫 시트). 첫 줄이 열 이름이고 값은 전부 글자로 읽는다
(`12.0` 이 아니라 `12`). 화면에 보이는 값과 저장된 값이 다를 수 있는 칸은 **읽지 않고 거부한다** —
날짜, 퍼센트, `00123` 같은 자릿수 서식, 수식 오류, 병합된 칸. 그 열을 `텍스트` 서식으로 다시 입력하거나
CSV 로 저장하면 된다. 구형 `.xls` 는 `.xlsx` 로 저장해서 쓴다. 엑셀에서 파일이 열려 있으면 읽을 수 없으니 닫는다.

## 실행

`실행` 은 준비 → 사전 준비 실행 → 학습 → 검증을 끝까지 간다(`vlmt pipeline line.yaml` 과 같은 일이다).
카드의 램프는 대기·진행·정상·NG 있음·오류이고 `통과 n · NG m` 이 같이 보인다. 아래 NG 표에 걸린 건이 사진과 함께 항상 보인다.

- NG 한 건을 누르면 한 줄 요약(몇 번 스테이션인지 포함)이 뜬다. `상세 보기` 에 원인과 해결이 있다.
- 고치는 길은 둘이다. ① 표(CSV)를 직접 고치고 `다시 읽기` 를 누른다. ② NG 한 건을 누르면 아래에 `이 건 고치기` 가
  뜬다 — 그 건의 칸을 고쳐 `저장 후 다시 읽기` 를 누르면 **고친 칸만** 표에 쓰고, 처음 고칠 때 원본을 `표.bak.csv` 로
  남긴다(건 이름 열은 고치지 않는다). 고친 건은 다시 실행하면 NG 목록에서 사라진다.
- 고칠 방법이 없는 건은 `이 건 제외` 를 누른다. 행을 지우지 않고 표의 `제외` 열에 `x` 를 적는다. 그 행은 읽을 때 건너뛰고,
  제외한 건수는 NG 표 위에 계속 보인다(`NG 3건 · 제외 2건`). 되살리려면 `x` 를 지우고 `다시 읽기`.
- 화면에서 고치는 것은 CSV 뿐이다. 엑셀(`.xlsx`)은 읽기 전용이라 CSV 로 저장해 쓴다.
  터미널에서도 된다: `vlmt row-set line.yaml <건> 열=값 …`, `vlmt row-exclude line.yaml <건> [--undo]`.
- **정답 노출 검사**(질문에 정답 낱말이 섞였는지)와 **정답 형식 검사**는 화면에서 끌 수 없다.
  걸린 건은 ③ 에서 NG 로 배출된다.

## 설정

카드를 누르면 오른쪽 설정 칸에 기본 설정이 보인다. `전문가 모드` 를 켜면 모든 설정과 안쪽 상자의 값이 보인다.
**학습량**은 적게 · 보통 · 많게다(보통이 파일의 값, 적게 0.5배, 많게 2배). 단계별 횟수를 직접 적는 것은
전문가 모드에서만 되고, 학습량과 같이 쓸 수 없다.

## 안쪽 보기와 내보내기

카드를 우클릭해 `펼치기` 를 누르면 그 스테이션 안쪽의 상자와 배선이 같은 화면 안에서 읽기 전용으로 보인다(`접기` 로 닫는다).
상자를 더하거나 배선을 고치려면 `11노드로 내보내기` 를 쓴다. 내보낸 뒤에는 5노드와 연결이 끊긴다.

## 검증 결과 — `검증 결과`

학습에 쓰지 않은 사진에 모델이 낸 답을 정답과 나란히 본다. 항목마다 O/X 가 붙지만 **참고용**이다.
빈 답과 형식이 어긋난 답은 따로 표시된다. 건마다 사람이 OK / NG 를 누른다(다시 누르면 미판정).
점수 합계는 내지 않는다. 판정은 `runs/<id>/infer/judgments.jsonl` 에 남고, 터미널에서도 된다.

```
vlmt judgments <실행 id>             # 건마다 O/X 와 판정
vlmt judge <실행 id> <건 id> ok|ng|none
```

## 오류 읽는 법

한 줄 요약에 몇 번 스테이션인지가 먼저 나온다(예: `③ 정답 형태 — …`). `상세 보기` 는 네 가지를 담는다:
어느 값이 어긋났는지 · 안 잡혔다면 언제 어디서 터졌을지 · 추정 낭비 · 어떻게 배선하면 되는지.
