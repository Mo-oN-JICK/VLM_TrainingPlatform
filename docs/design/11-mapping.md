## 11.6 우리만 있는 것

| 우리 개념 | 대응 Mech-Vision 개념 | 도입 이유 |
|---|---|---|
| 4중 게이트(G1~G4) | 부분 대응(타입 검사, 실행) | 실패 비용의 비대칭. 비전은 몇 초, 우리는 수십 시간 |
| 자원 예산 검사(G4) | 없음 | 단일 4090 24GB에서 OOM 하나가 다른 모든 실험을 막는다 |
| dry-run(G3) | 부분 대응(단일 Step 실행) | 전 노드를 샘플 1건으로 통과시켜 shape·스키마·토큰 길이를 실측 |
| 물질화 경계 | 없음 | 전처리와 학습이 한 장의 GPU를 두고 경쟁하는 문제 |
| 정답 누설 taint 검사 | 없음 | 완주하고 높은 점수를 내는 무효 실험이 가장 비싸다 |
| inference contract | 없음 | 학습 전처리와 추론 전처리의 불일치를 구조적으로 차단 |
| `runtime_profile` 허용 목록 | 없음 | Windows 단일 GPU에서 돌지 않는 옵션이 기본값이 되는 것을 막는다 |
| Trainer의 선언형 다단계 설정 | 부분 대응(Step 파라미터) | 조건 분기·반복은 그래프 표현이 부적합 |
